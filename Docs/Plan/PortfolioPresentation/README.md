# Interactive Exhibition PPT 정리 문서

이 폴더는 `InteractiveExhibition` 프로젝트를 포트폴리오 PPT로 만들기 위한 핵심 자료를 분리해 둔 문서 모음이다.

## 문서 구성

- `01-PROJECT-OVERVIEW.md`: 프로젝트 기획, 사용자 흐름, 현재 완성된 기능
- `02-TECH-STACK-AND-DECISIONS.md`: 사용 기술과 선택 이유
- `03-PROBLEM-SOLVING-CASE-STUDIES.md`: 실제 문제와 해결 과정
- `04-REPRESENTATIVE-CODE-MAP.md`: PPT에 넣기 좋은 대표 코드 위치
- `05-BLUE-GARAGE-ROLE-FIT.md`: Blue Garage 공고 기준 적용 내용과 부족한 점
- `06-GENERAL-COMPANY-PITCH.md`: 다른 기업 지원에도 쓸 수 있는 범용 어필 포인트

## PPT 권장 흐름

1. 프로젝트 한 줄 소개
2. 전체 구조도: Unreal Client / Local ASP.NET Server / Mobile Panel / Azure AI Gateway
3. 주요 기능 시연 흐름
4. 기술 선택 이유
5. 문제 해결 사례 3개
6. AI/RAG/Streaming 적용 방식
7. 배포 구조와 보안 설계
8. 지원 직무별 연결 포인트
9. 부족한 점과 다음 개선 계획

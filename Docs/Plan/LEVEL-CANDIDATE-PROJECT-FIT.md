# Level Candidate Project Fit

작성일: 2026-04-22

목적:

- 현재 프로젝트의 목표인 `모바일 웹 패널 -> 로컬 서버 -> Unreal 클라이언트`
- 캐릭터 이동/반응
- 전시형 공간 연출
- 향후 특정 상호작용 기반 영상 재생
- 추가 확장으로 SBS 3D 영상 또는 XREAL 관람 시나리오

에 얼마나 잘 맞는지 기준으로 전시 레벨 후보를 비교한다.

## 1. 현재 프로젝트 기준 평가 축

평가 기준은 다음 다섯 가지다.

1. 전시장 분위기
2. 캐릭터 데모 동선 확보
3. 영상 재생 스크린/벽면 확장성
4. 초반 구현 난이도
5. 향후 재사용성

## 3. 프로젝트 적합도 해석

### 3.1 Showroom Expo Hall

장점:

- TV 스크린과 영상 교체 방향이 이미 자연스럽다
- 구조가 단순해 모바일 패널 데모와 캐릭터 동선을 빠르게 붙일 수 있다
- 작은 예산으로도 시연 장면을 만들기 쉽다

리스크:

- "전시장"보다 "쇼룸/스테이지" 느낌이 조금 강할 수 있다
- 미술관/박물관 감성은 별도 소품 보강이 필요할 수 있다

적합 판단:

- `빠른 MVP`
- `영상 재생 확장`
- `데모 구역 중심 시연`

에는 매우 적합하다.

### 3.2 Museum Art Gallery

장점:

- 이름 그대로 전시/박물관/갤러리 감성이 분명하다
- 데모 맵과 그림 교체 구조가 있어 포트폴리오 설명력이 좋다
- 캐릭터, 그림, 소품, 공간 연출을 묶기 쉽다

리스크:

- 가격이 `Showroom Expo Hall`보다 높다
- 영상 스크린 연출은 직접 추가해야 할 수 있다

적합 판단:

- `전시장 느낌`
- `포트폴리오 화면빨`
- `안정적인 미술관형 데모`

를 원하면 좋은 선택이다.

### 3.3 Modular Exhibition/Gallery

장점:

- 가장 구조적으로 프로젝트와 잘 맞는다
- 전시 공간을 직접 설계하고 커스텀하기 쉽다
- 향후 상호작용 지점, 영상 스크린, SBS 관람 존 같은 확장을 설계하기 좋다
- WebGL/VR 전시 사례 언급이 있어 전시 시스템용 베이스로 해석하기 좋다

리스크:

- 바로 "완성 화면"이 나오기보다 조립과 세팅이 필요하다
- `virtual texture support` 등 초기 설정 점검이 필요하다
- 가격 확인이 먼저 필요하다

적합 판단:

- `단순히 예쁜 레벨 구매`보다
- `실제 전시 구조를 설계하고 이후 프로젝트까지 재사용할 베이스`

를 원할 때 가장 유력하다.

### 3.4 Modern Art Gallery / Art Gallery Showroom

장점:

- 시각적 인상이 좋다
- 포트폴리오 첫인상에 유리하다
- 그림 교체와 소규모 갤러리 연출에 적합하다

리스크:

- 영상 재생과 상호작용 구조는 직접 붙여야 한다
- 캐릭터 이동/상호작용 데모에 최적화된 레벨인지 별도 확인 필요

적합 판단:

- `비주얼 우선`
- `짧은 갤러리형 시연`

에는 좋지만, 시스템 확장성은 `Modular Exhibition/Gallery` 쪽이 더 낫다.

## 4. 내 프로젝트 기준 추천 순위

### 1순위: Modular Exhibition/Gallery

전제:

- Personal 가격이 예산 범위 안일 때

이유:

- 현재 프로젝트와 다음 프로젝트 확장성까지 고려하면 가장 구조 친화적이다
- 전시 시스템이라는 기획에 가장 잘 맞는다
- 영상 재생과 상호작용 포인트를 추가하기 좋다

### 2순위: Showroom Expo Hall

이유:

- 가격이 상대적으로 접근 가능하고
- 영상 재생 확장을 붙이기 쉽고
- 빠르게 MVP 시연 결과를 만들 수 있다

### 3순위: Museum Art Gallery

이유:

- 전시장 감성이 좋고
- 포트폴리오 화면이 잘 나올 가능성이 높다
- 다만 가격과 커스텀 난이도는 조금 더 본다

## 5. XREAL / SBS 시나리오까지 고려한 판단

향후 XREAL 1S 또는 SBS 3D 영상 시연까지 고려하면 레벨은 아래 조건이 중요하다.

- 스크린/벽면/프로젝션 위치를 자연스럽게 만들 수 있는가
- 특정 상호작용 지점에서 영상을 재생할 수 있는가
- 관람자가 "영상 보는 존"을 명확히 인식할 수 있는가

이 관점에서는

- `Modular Exhibition/Gallery`
- `Showroom Expo Hall`

이 두 개가 가장 유리하다.

## 6. 최종 결론

한 줄 결론:

- `가장 실무적으로 맞는 후보`: `Modular Exhibition/Gallery`
- `가장 빨리 MVP 결과 내기 좋은 후보`: `Showroom Expo Hall`

따라서 구매 전 최종 확인 순서는 아래가 좋다.

1. `Modular Exhibition/Gallery` Personal 가격 확인
2. 예산 내면 그것을 우선 고려
3. 예산 초과면 `Showroom Expo Hall`로 바로 전환
